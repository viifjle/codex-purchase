## 先搞清楚：你要买的东西到底是什么

现在的 Codex 和 2021 年那个给早期 GitHub Copilot 供能的 Codex 模型不是一回事。2025 年重启之后，它已经是一套完整的 agent 开发环境：给它一个任务，它会自己读仓库、改文件、跑测试、修报错，最后把改动打包成 diff 或 pull request，而不是只给你几行代码让你自己贴。

- **ChatGPT 里的云端 agent**：在网页或桌面端描述任务，它把你的 GitHub 仓库克隆到隔离容器里干活，多个任务可以并行，跑完直接开 PR；

关键是：这些形态共用同一个 ChatGPT 账号和同一个额度池。所以「购买」这个动作只有一个——订阅 ChatGPT 套餐，然后所有入口都能用。

## 开通之后：三个入口

订阅生效后，用同一个 ChatGPT 账号登录即可，三步就能跑起来：

1. **网页端**：在 ChatGPT 网页版打开 Codex 区块，连接 GitHub 并授权仓库，就能派发云端任务；
2. **终端 CLI**：装好后在项目目录运行，它会在本地读代码、改文件、跑测试，沙箱范围和审批策略都能配置；
3. **IDE 插件**：VS Code 或 JetBrains 装上插件，用同一个账号登录。

桌面端的话，去 ChatGPT 官网的下载页拿应用，切到 Codex 模式就行；已经装了 CLI 的，终端里敲 `codex app` 可以直接调起。注意桌面应用目前只支持 Apple Silicon 的 Mac 和 Windows 11，Intel Mac 和 Linux 用户走 CLI。

两个提升体验的细节值得知道。一是桌面应用支持多个任务并行，每个任务在独立的 git worktree 里跑，互不打架，还能用手机远程看进度、批准或拒绝命令。二是在项目根目录放一个 AGENTS.md，写清楚技术栈、构建命令和禁区，agent 的表现会明显更稳——这个格式是开放的，以后换别的工具也能直接带走。

也有一处要想清楚：云端模式是把仓库克隆到 OpenAI 的基础设施上跑，整个流程围绕 GitHub 展开。介意代码出本地的话，用本地 CLI 模式就好。

顺带一提，开通 Plus 之后，账号上的 GPT-6、Deep Research 等权益也会一并可用，不只 Codex。

形式上能，但额度只是象征性的，模型也是入门配置。实际干活至少 Plus 起步。

**Plus 的额度到底够不够？**

多数个人开发者按正常强度用一周，撞不到上限。如果你让 agent 每天连跑几个小时、经常碰到周上限，Pro 多出来的空间才值回差价。

**额度用完了怎么办？**

等窗口或周期刷新，或者升级套餐。周上限是硬顶，被卡住时升级是最直接的办法。

**开通之后还要自己审代码吗？**

要。Codex 完成常规任务很稳，但任务描述含糊时，它可能漂亮地把错误的东西做出来。把任务当成一份小规格说明书来写，合并前照常过一遍 diff。
